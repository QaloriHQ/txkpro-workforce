- Revised 14-week Phase 1 Pilot Center
- Expanded Student Readiness profile
- Updated referral evidence and reporting

IMPORTANT PRODUCT RULE
PRO Points augment, but do not replace, Instructor Verified Skills.

Verified Skills remain the authoritative source for demonstrated technical competency.
PRO Points capture transparent, observable professional-readiness and engagement activity.

External statistics contained in the Institution pitch strategy are treated as source-provided
benchmarks and must remain visually separate from TXKPRO platform telemetry unless
independently validated and intentionally published.

8. VERIFIED SKILLS
======================================================================

Verified Skills remain authoritative technical competency evidence.

Statuses:

- Not Started
- Self-Attested
- In Progress
- Ready for Review
- Instructor Verified
- Needs More Practice
- Revoked

FLOW

Student self-attests / progresses
→ Instructor reviews
→ Verify / Needs Practice / Not Assessed
→ Verification record stored
→ Employer-visible technical evidence

ASSISTANT INSTRUCTOR FLOW

Assistant:
Ready for Instructor Review

Instructor:
Reviews
→ authoritative verification

PRO POINTS CONNECTION

A verified skill may trigger a transparent Skill Mastery point event.

Example:
Residential Rough-In verified
+75 Skill Mastery PRO Points

The point event is a consequence of verification.
It does not become the verification itself.
